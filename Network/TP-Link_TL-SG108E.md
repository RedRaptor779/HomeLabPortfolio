# TP-Link TL-SG108E Easy Smart Managed Switch
The TP-Link switch provides Layer 2 connectivity for the homelab network. The [Cisco ASA](https://github.com/RedRaptor779/HomeLabPortfolio/blob/main/Network/Cisco_ASA_5506-X.md#cisco-asa-5506-x) does not have 
layer 2 capability, so a switch was required for Layer 2.
